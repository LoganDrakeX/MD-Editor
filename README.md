# MD-Editor

Wiki 风格的 VS Code Markdown 编辑器插件：**WYSIWYG / 源码 / 预览** 三模式，粘贴图片自动保存到 md 同目录的 `images/` 子目录，支持 `[[Wiki 双链]]` 跳转。

## 功能

- **Jira 风格编辑栏**：模式下拉（只显示当前模式，点击展开其他选项）、段落样式下拉（普通文本/H1~H6/代码块）、大纲开关、加粗/斜体/删除线、无序/有序/任务列表、代码块、表格（**6×6 网格选行列**）、链接/图片/分割线、撤销重做、表情插入；**格式按钮带选中态高亮**（光标在对应格式内时图标高亮，再次点击取消，空选区应用格式也准确）；浅色/深色主题一键切换（`mdEditor.theme`：auto/light/dark，auto 跟随 VS Code）。
- **列表互斥转换**：光标在列表中时，点击其他列表类型（无序/有序/任务）会把**整个列表**转换为目标类型，不会创建嵌套子列表；不在列表中点击任务列表会新建任务项。
- **表格编辑（Obsidian 风格）**：鼠标悬停**行/列边界**出现小圆点（悬停变 **+ 号**，边界线同步高亮），点一下即在对应位置插入一行/列；悬停**行头/列头**出现 **6 点手柄**，点击选中整行/整列并弹出设置菜单（插入/删除/移动/对齐/全选表格）。
- **图片调整大小**：WYSIWYG 中点击图片出现右下角手柄，拖拽调整宽度；以 `{width=400}` 后缀（Pandoc 风格）持久保存到图片 Markdown 之后，本插件预览正确应用宽度。
- **代码高亮**：WYSIWYG 代码块与预览均支持 highlight.js 语法高亮（可编辑层 + 高亮覆盖层，不打断输入）；输入 ```` ```js ```` 自动识别语言；**代码块右上角语言角标可点击直接切换语言**；**浅色主题用浅色代码配色（GitHub 风格）、深色主题用深色配色**。
- **格式气泡**：WYSIWYG 中光标/选区命中加粗、斜体、删除线、行内代码、链接时，光标旁弹出气泡**显示对应的 Markdown 源码片段**（加粗显示 `**加粗**`、链接显示链接地址等），可一键移除/切换格式，链接可直接改地址或移除。
- **左侧大纲**：默认显示，点击跳转到对应标题（三种模式都支持，跳转后标题置于可视区顶部）；**行内代码高亮渲染**（保持正常文字颜色，不再显示反引号）；标题旁的**折叠/展开按钮**（▾/▸）可只显示一级标题；右缘可**拖动调整宽度**；工具栏"加粗"左侧的**树状大纲图标**可随时隐藏/显示。
- **表格编辑**：光标进入表格时顶部工具栏出现**表格操作行**（不悬浮、不遮挡表格）——选中行/列/全表、行列增删、整行上下移/整列左右移、左/中/右对齐（持久保存为 `:---:`）。
- **三模式切换**：顶部标签一键切换 WYSIWYG（Milkdown 所见即所得）/ 源码（CodeMirror 6）/ 预览（markdown-it 渲染）；单一数据源，切换不丢内容。
- **自动保存**：编辑防抖后自动写回文件（可在设置调整间隔），外部改动文件会自动刷新面板。
- **粘贴图片**：任意模式下 `Ctrl+V` 截图/图片或拖入图片 → 自动存入 md 同目录 `images/` 子目录 → 光标处插入引用并立即显示。
- **Wiki 双链**：预览模式下 `[[笔记名]]`（或 `[[笔记名|别名]]`）渲染为可点击链接；点击跳转同目录/工作区同名文件，不存在时可一键创建。
- **快捷键**：`Ctrl+Alt+M`（macOS: `Cmd+Alt+M`）打开当前 Markdown 的编辑器面板。

## 使用

1. 打开一个 `.md` 文件；
2. 按 `Ctrl+Alt+M`，或在命令面板执行 **MD-Editor: 打开当前 Markdown**；
3. 顶部切换模式、使用格式化按钮（WYSIWYG 下可用），编辑内容自动保存；
4. 直接粘贴图片体验图片自动归档。

> 已知边界：Markdown 表格格式无法承载单元格背景色与垂直对齐（GFM 只有水平对齐 `:---:`），需要可后续做 HTML 表格模式；图片宽度语法 `{width=N}` 为本插件与 Pandoc 约定的扩展语法，VS Code 内置预览/GitHub 会按原图大小显示。

## 设置（`settings.json`）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `mdEditor.defaultMode` | `wysiwyg` | 打开面板时的默认模式 |
| `mdEditor.imageFolder` | `images` | 粘贴图片的保存子目录名（相对 md 文件） |
| `mdEditor.imageNameMode` | `timestamp` | 图片命名策略：`original` / `timestamp` / `timestamp-original` |
| `mdEditor.autoSaveDelay` | `800` | 写回文件的防抖毫秒数 |
| `mdEditor.syncFromDisk` | `true` | 外部改动文件时自动刷新面板 |
| `mdEditor.splitView` | `false` | 预留：上编辑下预览分屏 |
| `mdEditor.enableWikiLinks` | `true` | 预留：WYSIWYG 双链渲染 |
| `mdEditor.theme` | `auto` | 界面主题：`auto`（跟随 VS Code）/ `light`（Jira 浅色）/ `dark`（深色） |

## 开发

```bash
npm install
npm run build     # 构建扩展 + webview
npm run watch     # 增量构建
npm test          # 命名单测 + webview 冒烟测试
npm run package   # 生产构建（minify）并打包 .vsix
```

按 `F5` 启动扩展开发宿主（Extension Development Host），打开一个 md 文件后按 `Ctrl+Alt+M` 测试。
